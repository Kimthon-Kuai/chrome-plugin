为双语阅读而生

AI Translator 把翻译能力嵌进浏览流：不必复制到别处，不必切换标签页。选中即译，整页可换，也可以原文与译文并排对照；长文可先看总结。接口遵循 OpenAI Chat Completions，可对接 DeepSeek 等兼容服务。

  • 自备密钥 API Key 与 Base URL 本地保存，不经过第三方中转。
  • 中英互译 支持自动检测，也可固定源语言与目标语言。
  • 管理面板 历史记录与 Token 消耗一目了然。
  • 双语对照 保留原文，译文紧随其下，可随时切回覆盖翻译。

核心功能

四项能力，覆盖日常浏览的翻译需求。

全页面翻译

一键换上整页译文

对当前页可见文本批量翻译，保留原有结构。译完可随时还原原文，适合快速通读外文站点。

双语对照

原文与译文，并排读完一句

对照模式保留原文，在句中下方显示译文，适合学习与术语核对。已翻译的页面可在覆盖与对照之间原地切换，无需重新调用接口。

安装步骤

当前以 Chrome 开发者模式加载未打包扩展。完成下列四步即可使用。

  1. 1

    打开扩展管理页

    在 Chrome 地址栏访问 chrome://extensions/

  2. 2

    开启开发者模式

    打开页面右上角的「开发者模式」开关。

  3. 3

    加载已解压的扩展程序

    点击「加载已解压的扩展程序」，选择本项目根目录。

  4. 4

    填写 API 并开始翻译

    打开管理面板，配置 API Key、Base URL 与模型；之后即可全页翻译、双语对照、划词或总结。

    翻译方式在弹窗或管理面板里切换：覆盖翻译，或双语对照（原文保留、译文在下）。

提示：密钥仅保存在浏览器本地存储。兼容任意 OpenAI 协议接口，例如 DeepSeek（https://api.deepseek.com）。
